Ce qui vous fait perdre des clients aujourd'hui

Une fiche Google à 86 avis que personne n'a revendiquée

La fiche « Saut à l'élastique près de Millau » (4,9, 86 avis) affiche le bouton « Revendiquer cet établissement », aucun horaire, et l'adresse « Unnamed Road, 12230 Sainte-Eulalie-de-Cernon ». Tant qu'elle n'est pas revendiquée, n'importe qui peut le faire à votre place, et vous ne pouvez ni répondre aux avis ni corriger les horaires. Vos avis sont dispersés sur trois fiches : « ANTIPODES Sport Nature », « Antipodes bureaux » (3e sur « accrobranche Millau ») et celle-ci.

Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un saut à l'élastique près de Millau ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a ni l'un ni l'autre : /llms.txt répond « page introuvable », et le code ne contient aucune fiche d'identité, pas même une « organisation ». Pour un assistant IA, vous êtes une belle page sans nom ni adresse, alors que vous êtes là depuis 25 ans.

Un site web de 2018 qui change de nom en route

antipodes-millau.com renvoie vers activites-loisirs-millau.com : le client qui tape votre nom arrive sur un autre nom de domaine. Le code porte la signature « Copyright 2002-2018, DNN Corporation », une plateforme que plus personne ne fait évoluer ; il n'y a pas de plan de site web (/sitemap.xml répond « page introuvable ») et aucune page n'a d'adresse de référence (balise canonical). Google explore un site web sans carte, sous deux noms.

Pas d'adresse email sur le site web

La page « Contact / Devis Groupes » (178 mots) ne donne que le 05 65 60 72 03 : contact@antipodes-millau.com n'apparaît nulle part sur le site web, seulement sur votre page Facebook. Un comité d'entreprise ou une classe qui veut un devis écrit ne sait pas où écrire.

Des pages de réservation sans titre principal

La page « Activités / Réservation » (382 mots) n'a pas de titre principal (balise H1), celui que Google lit en premier ; la page Contact non plus. Le pied de page affiche « Copyright © 2026 », le code « 2002-2018 ».
