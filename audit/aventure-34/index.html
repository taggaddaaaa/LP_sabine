Ce qui vous fait perdre des clients aujourd'hui

Le plan de site web envoyé à Google pointe vers un autre site web, daté de 2017

Le fichier /sitemap.xml de aventure34.com liste 50 adresses, toutes sur un autre nom de domaine, canyoning-speleologie.fr, avec une dernière modification au 28 mars 2017. C'est la carte que Google utilise pour explorer votre site web, et elle le renvoie ailleurs. Aucune page n'a non plus d'adresse de référence (balise canonical) : Google doit deviner laquelle compte.

Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un canyoning dans l'Hérault ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a pas de llms.txt (« page introuvable »), et la fiche d'identité du code s'appelle « Canyoning Hérault », sans adresse, sans téléphone, sans vos 237 avis : pour un assistant IA, votre entreprise n'a pas de nom et pas de lieu.

Aucune mention légale, et « CONTACT par mail » sans adresse email

L'adresse /mentions-legales répond « page introuvable » et aucun lien du site web n'y mène. Le pied de page affiche « CONTACT par mail », mais aucune adresse email n'apparaît sur le site web, pas même sur la page Contactez-nous : un groupe qui veut un devis écrit doit passer par le formulaire. Ce n'est pas un reproche, c'est souvent oublié, mais les mentions légales sont obligatoires.

Des pages sans description, et un titre sans accent

Le titre de l'onglet est « Canyoning Herault », sans accent, sur l'accueil et dans la fiche d'identité du code ; les pages Contact (228 mots) et Escalade (224 mots) n'ont ni description ni, pour Contact, titre principal. Ce sont les textes que Google affiche dans ses résultats.

68 images sans chargement différé

L'accueil charge 68 images d'un coup, dont le bandeau bande.jpg de 401 Ko, pour 140 Ko de code. Sur un téléphone en 4G au pied du Caroux, c'est ce qui fait partir un visiteur avant d'avoir vu les cascades.
