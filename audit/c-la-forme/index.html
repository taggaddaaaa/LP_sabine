Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « une salle de sport près de Mauguio ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a ni l'un ni l'autre : /llms.txt répond « page introuvable », et le code ne contient aucune fiche d'identité : ni nom, ni adresse, ni horaires, ni tarifs, ni votre note. La description pour Google (balise meta description) est vide sur les 11 pages. Pour un assistant IA, C La Forme est une page sans nom ni adresse, et vos tarifs n'existent pas.

Vos tarifs, vos horaires et votre planning sont des images

La page « C Quand ? C Combien ? » affiche les tarifs (250 € l'année, 35 € le mois, séance d'essai offerte) et les horaires dans une image (image.jpg du 22 septembre 2024), et le planning des cours collectifs est une autre image (image.png du 25 octobre 2026). Google, les assistants IA et les lecteurs d'écran n'y lisent rien : quelqu'un qui tape « salle de sport Mauguio tarif » ou « cours collectifs Carnon horaires » ne trouve ni vos 35 € par mois, ni votre séance d'essai offerte. Sur les 198 images du site web, aucune n'a de description utile : 187 vides et 11 « Site de claforme ! ».

Une page d'accueil de 9,3 Mo

Relevé du 6 novembre : l'ouverture de l'accueil télécharge 9,29 Mo en 21 requêtes, dont une seule image de fond de 8,1 Mo (backgroundarea/…/image.jpg, mise en ligne le 5 août 2020 à sa taille d'origine). Sur un téléphone en 4G, c'est ce qui fait partir un visiteur avant d'avoir vu la salle, et Google en tient compte dans son classement.

Jimdo gratuit : une adresse qui n'est pas la vôtre, et sa publicité

Votre site web vit à l'adresse claforme.jimdofree.com : le nom de domaine appartient à Jimdo, chaque page s'intitule « … - Site de claforme ! » et le pied de page affiche la publicité de Jimdo (« Inscrivez-vous gratuitement sur https://fr.jimdo.com »). La version gratuite n'a ni nom de domaine à vous, ni description pour Google sur vos pages, ni fiche d'identité dans le code. C'est pour ça que je ne travaille pas le référencement sur Jimdo : je refais le site web, à une adresse à vous, et il vous appartient.

Des mentions légales qui sont le texte d'exemple de Jimdo

Le lien « Mentions légales » du pied de page ouvre la page /about/, dont tout le contenu est le texte de démonstration de Jimdo (« Sélectionner un design, le personnaliser en quelques clics, ajouter différents contenus, et voilà ! »). Ni le nom de l'association, ni son siège, ni le directeur de publication, ni l'hébergeur n'y figurent. Ce n'est pas un reproche, Jimdo ne prévient pas, mais c'est obligatoire pour toute association qui publie un site web, et c'est vite corrigé.

Un lien Facebook qui demande de se connecter, un TikTok sans lien

Le bouton Facebook du site web ouvre un groupe (facebook.com/groups/144915165851093) : un visiteur qui n'est pas connecté à Facebook tombe sur l'écran de connexion, et personne ne peut voir vos soirées ni vos sorties avant d'adhérer. La page Contact cite TikTok (c.la.forme) sans lien. Instagram (c.la.forme.carnon) est bien relié depuis chaque page.
