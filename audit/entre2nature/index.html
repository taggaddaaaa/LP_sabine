Ce qui vous fait perdre des clients aujourd'hui

WordPress 4.2.5 : la version de 2015, jamais mise à jour

Le code de votre site web et son flux déclarent WordPress 4.2.5, sortie en 2015 : nous en sommes à la version 7.1. Onze ans de correctifs de sécurité manquants, avec un éditeur de pages (Visual Composer) et une extension de traduction (qTranslate-X 3.4.6.4) qui ne sont plus maintenus. Un site web dans cet état peut être piraté ou cesser de s'afficher à n'importe quelle mise à jour de l'hébergeur. Vu l'écart, le remettre à jour coûterait plus cher que de le refaire proprement.

Un article sur le shilajit, sans rapport avec vos sorties

Le plan du site web liste, en date du 7 octobre 2026, un article « Shilajit : comment une résine se forme sur des siècles, et comment la choisir sans se tromper ». Il n'a rien à voir avec le canyoning. Ce type de publication sur un WordPress non mis à jour est souvent le signe d'un accès non maîtrisé ou d'un article sponsorisé qui dilue votre sujet aux yeux de Google. À vérifier, et à retirer.

Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un canyoning près de Montpellier ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a ni fiche d'identité dans le code (seulement un bloc « WebSite », sans adresse, sans zone, sans vos 640 avis), ni fichier /llms.txt (il répond 404). Pour un assistant IA, le premier canyoning de Montpellier n'a ni nom ni adresse.
