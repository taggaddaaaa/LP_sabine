Pas assez de contenu pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un chauffeur privé à Montpellier ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Wix a créé le llms.txt tout seul et une fiche d'identité minimale (nom, adresse), mais ni votre zone, ni vos prestations, ni vos 107 avis n'y figurent. Un assistant IA sait que vous existez, pas ce que vous valez.

Wix vous loue votre site web

Un site web Wix ne se déménage pas : si vous arrêtez l'abonnement, il disparaît, et les réglages de référencement local y restent limités. C'est pour ça que je ne travaille pas le référencement sur Wix : je refais le site web, et il vous appartient.

Deux adresses de site web sur la fiche Google, dont une qui ne répond pas

Votre fiche Google affiche deux sites web : onevtcprestige.com et one-vtc-prestige.com. Le premier ne répond pas (relevé du 25 octobre). Un client qui clique dessus tombe sur une page d'erreur ; Google, lui, voit une incohérence.

Une page d'accueil de 900 Ko de code

Le code de l'accueil pèse 898 Ko avant même les 49 images. Sur un téléphone en 4G, c'est ce qui fait partir un visiteur avant d'avoir vu vos véhicules.
