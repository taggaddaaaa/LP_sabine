Ce qui est déjà bien

Ce qui vous fait perdre des clients aujourd'hui

Une boutique en 8.6.4 quand la 11.2.2 est sortie

Votre module de réservation en ligne, WooCommerce, affiche sa version dans le code : 8.6.4, publiée début 2024, alors que la version actuelle est la 11.2.2 ; l'extension de traduction WPML est en 4.6.9. Ce n'est pas un reproche : ces mises à jour se font à la main, avec le risque de casser le paiement, et ce n'est pas votre métier. Mais une boutique en retard, c'est par là qu'arrivent les spams et les fausses commandes, et Google n'aime pas ça. C'est exactement ce que je prends en charge : les mises à jour sont faites pour vous, chaque mois, et vous n'y pensez plus.

Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un paintball près d'Alès ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a ni l'un ni l'autre : /llms.txt répond « page introuvable », et le code ne décrit qu'une « page web » : ni adresse, ni horaires, ni tarifs, ni vos 62 avis. Pour un assistant IA, Paintball Gard est une belle page sans nom ni adresse.

Des mentions légales qui parlent d'un autre site web

Vos mentions légales commencent par « Le site www.paintballgard.com est le site… », alors que votre site web est paintballgard.fr, et l'adresse de contact est en @paintballardeche.fr : trois noms de domaine pour une seule entreprise. Google et vos clients préfèrent un seul nom, le même partout.

Pas d'Instagram, un seul réseau relié

Le site web ne renvoie que vers Facebook. Un paintball vit de photos et de vidéos de parties : un compte Instagram relié au site web et à la fiche Google manque. Et le 7 novembre, votre fiche Google n'affiche aucun horaire (« Ajouter des horaires »).
