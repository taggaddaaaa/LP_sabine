Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un dépanneur à Montpellier, maintenant ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a ni l'un ni l'autre : /llms.txt répond « page introuvable » (erreur 404) et le code ne contient qu'une fiche « WebSite », sans adresse, sans zone, sans services, sans vos 522 avis. Pour un automobiliste en panne qui demande à son téléphone, vous n'existez pas.

Un formulaire de contact sans politique de confidentialité

La page Contact invite à remplir un formulaire, mais /politique-de-confidentialite/ répond « page introuvable ». Dès qu'un site web collecte un nom ou un numéro, cette page est obligatoire. Ce n'est pas un reproche, c'est souvent oublié à la mise en ligne.

Un pied de page figé en 2024, un plan du site web à une adresse inhabituelle

Le bas de page affiche « 2024 Prestige assistance Montpellier », et le plan du site web est rangé à /sitemaps.xml au lieu de l'adresse standard /sitemap.xml : il est bien déclaré dans robots.txt, mais les outils qui cherchent l'adresse habituelle ne le trouvent pas.

Vos 522 avis ne sont pas sur votre site web

Pas un avis affiché sur l'accueil, pas de lien vers une page Facebook ou Instagram. Pour quelqu'un dont la voiture vient de s'arrêter, voir « 5,0 sur 522 avis » avant d'appeler, c'est ce qui le fait choisir vous plutôt que le premier résultat.
