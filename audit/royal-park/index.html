Ce qui vous fait perdre des clients aujourd'hui

« Nothing Found » en titre d'accueil, des pages de 40 mots

Le titre principal de votre page d'accueil (balise H1) est « Nothing Found » : le message d'erreur du modèle quand il ne trouve rien à afficher. Les pages Accueil, Anniversaire, Événements, Horaires, Jeux, Plan, Professionnels et Tarifs comptent 40 mots chacune, c'est-à-dire le menu et le pied de page, sans contenu. Un parent qui cherche vos tarifs ou vos horaires ne trouve rien, et Google non plus.

Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un parc de jeux pour enfants à Nîmes ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Votre site web n'a ni l'un ni l'autre : /llms.txt répond « page introuvable », et le code ne contient aucune fiche d'identité : ni nom, ni adresse, ni horaires, ni tarifs, ni vos 469 avis. Pour un assistant IA, Royal Park est une page vide.

Ni mentions légales, ni politique de confidentialité

/mentions-legales/ et /politique-de-confidentialite/ répondent « page introuvable », et aucun lien ne mène à ces pages. Ce n'est pas un reproche, personne ne prévient, mais c'est obligatoire pour toute entreprise, et c'est vite corrigé.

Un message « fermé pour travaux » de juillet encore affiché

Le 7 novembre, la dernière publication de votre fiche Google, datée du 12 juillet 2026, annonce « ROYAL PARK est fermé pour travaux et congé annuel. Prochaine ouverture le Samedi 15 Aout ». C'est le premier message qu'un parent lit en novembre : une publication par mois, c'est ce qui tient une fiche vivante.

Un modèle de clinique vétérinaire, et deux versions du site web

Le code révèle le thème utilisé : « The9 Pet Veterinary », un modèle conçu pour les vétérinaires. Et le site web répond aussi bien en http:// qu'en https:// sans rediriger l'un vers l'autre : pour Google, ce sont deux sites web identiques, et il ne sait pas lequel montrer.

Aucune description, aucun réseau

Pas une page n'a de description pour Google (balise meta description), et le site web ne renvoie vers aucun réseau social : pas de Facebook, pas d'Instagram, alors qu'un parc de jeux vit de photos d'anniversaires.
