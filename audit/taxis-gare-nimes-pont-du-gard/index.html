Wix vous loue votre site web

Un site web Wix ne se déménage pas : si vous arrêtez l'abonnement, il disparaît, et les réglages de référencement local y restent limités. C'est pour ça que je ne travaille pas le référencement sur Wix : je refais le site web, et il vous appartient.

Un Wix gratuit, avec la publicité de Wix sur chaque page

L'adresse de votre site web est fdzjules.wixsite.com/website, pas un nom de domaine à vous, et chaque page commence par « Ce site a été créé sur Wix. Créez le vôtre dès aujourd'hui ». Pour un voyageur qui compare deux taxis sur son téléphone, c'est le signal d'une entreprise qui n'a pas investi, alors que vous êtes la station officielle. Et le pied de page dit « ©2019 ».

Invisible pour ChatGPT et les assistants IA

Aujourd'hui, de plus en plus de gens ne tapent plus leur recherche sur Google : ils demandent directement à ChatGPT ou à un autre assistant IA « un taxi à la gare Nîmes Pont-du-Gard ». Pour recommander quelqu'un, ces assistants lisent les sites web et cherchent deux choses : une fiche d'identité cachée dans le code (qui vous êtes, où, quels services, vos avis) et un petit fichier de présentation pensé pour eux, le llms.txt, le nouveau standard de ce référencement. Wix a posé une fiche « LocalBusiness » minimale, mais sans vos services ni votre zone, et /llms.txt répond « page introuvable ». Aucune page ne dit que vous êtes les taxis officiels de la gare : un assistant IA ne peut pas le deviner.
